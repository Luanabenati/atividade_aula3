## 📌 Sobre a atividade

Nesta atividade, realizamos uma pesquisa sobre sites que apresentam diferentes aplicações de **tipografia, cores, layout, acessibilidade e experiência do usuário**.

Foram escolhidos sites considerados bons exemplos e sites que apresentam problemas de design e usabilidade.

Para cada site, analisamos:

* Vantagens;
* Desvantagens;
* Problemas encontrados;
* Possíveis soluções.

---

# ✅ Sites bons

## 1. Active Theory

🔗 https://activetheory.net/work

### Por que escolhemos?

O site apresenta uma experiência visual bastante trabalhada, utilizando elementos tridimensionais, partículas e recursos gráficos para apresentar seus projetos.

### Vantagens

* Uso de WebGL e partículas 3D;
* Experiência visual imersiva;
* Navegação diferenciada;
* Busca inteligente utilizando Inteligência Artificial;
* Apresentação dos projetos de forma cinematográfica.

### Desvantagens

* Pode exigir bastante processamento gráfico;
* Pode apresentar travamentos em computadores ou celulares mais antigos;
* A navegação em 3D pode dificultar quem procura informações rapidamente;
* Existem problemas relacionados à acessibilidade;
* Alguns elementos apresentam baixo contraste.

### 💡 Como melhorar?

Uma possibilidade seria disponibilizar um **Modo Minimalista / Lista 2D**, permitindo que o usuário visualize os projetos de maneira mais simples.

Também seria interessante detectar automaticamente o desempenho do dispositivo e diminuir a quantidade de partículas e efeitos em aparelhos com menor capacidade.

## 2. Samsy

🔗 https://samsy.ninja/works

### Por que escolhemos?

O site utiliza uma apresentação em 3D bastante avançada, criando uma experiência semelhante a um ambiente de jogo.

### Vantagens

* Uso de WebGPU/WebGL;
* Visual extremamente imersivo;
* Experiência diferenciada;
* Demonstra domínio de tecnologias gráficas;
* Grande impacto visual para apresentação profissional.

### Desvantagens

* Pode exigir hardware mais moderno;
* Dispositivos mais fracos podem apresentar travamentos;
* A utilização de avatar pode dificultar uma consulta rápida;
* Pode apresentar dificuldades para leitores de tela;
* Efeitos de luz e movimento podem incomodar alguns usuários.

### 💡 Como melhorar?

Poderia existir um botão bem visível para mudar para um **Modo Clássico 2D**, principalmente para usuários com computadores ou celulares mais fracos.

Também poderiam ser adicionadas opções para desativar efeitos muito intensos, como:

* Bloom;
* Glitch;
* Movimentos rápidos;
* Efeitos de piscar.

# ❌ Sites ruins

## 3. The Big Ugly Website

🔗 https://thebiguglywebsite.com/

### Por que escolhemos?

O site apresenta vários problemas visuais e de organização, sendo um bom exemplo para observar o que deve ser evitado em um projeto web.

### Vantagens

* É leve para carregar;
* Pode ser utilizado como exemplo didático;
* Permite identificar facilmente problemas de design.

### Desvantagens

* Imagens com links quebrados;
* Cores com contraste ruim;
* Texto vermelho/preto sobre fundo escuro;
* Falta de alinhamento;
* Layout desorganizado;
* Baixa acessibilidade.

### 💡 Como melhorar?

Seria necessário:

1. Corrigir os caminhos das imagens;
2. Utilizar uma paleta de cores mais harmoniosa;
3. Melhorar o contraste;
4. Utilizar fontes mais limpas e legíveis;
5. Organizar os elementos utilizando **Flexbox ou Grid**;
6. Melhorar a acessibilidade da página.

## 4. Yale School of Art

🔗 https://www.art.yale.edu/

### Por que escolhemos?

Apesar de possuir uma proposta artística e experimental, o site apresenta problemas de organização visual, legibilidade e acessibilidade.

### Vantagens

* Funciona como uma obra artística;
* Possui uma proposta visual diferente;
* O conteúdo pode ser editado por alunos e professores;
* Possui uma estrutura semelhante a uma wiki.

### Desvantagens

* Grande poluição visual;
* Fundo repetido;
* Textos com baixa legibilidade;
* Organização pouco clara;
* Problemas de acessibilidade;
* Navegação pode ser confusa.

### 💡 Como melhorar?

Algumas melhorias seriam:

* Utilizar fundos sólidos;
* Aumentar o contraste entre texto e fundo;
* Organizar melhor os menus;
* Separar as áreas de experimentação artística;
* Criar uma estrutura de navegação mais clara.

O próprio site informa que uma nova versão está prevista para o final de 2026.

# 🎯 Conclusão

A pesquisa mostrou que um bom site não depende apenas de ter uma aparência bonita.

É importante encontrar um equilíbrio entre **estética, tipografia, cores, organização, desempenho e acessibilidade**.

Os sites Active Theory e Samsy apresentam experiências visuais muito avançadas, mas podem exigir mais do dispositivo e dificultar a navegação para alguns usuários.

Já The Big Ugly Website e Yale School of Art mostram como escolhas inadequadas de cores, organização e tipografia podem prejudicar a experiência do usuário.

Dessa forma, o desenvolvimento de uma página deve considerar tanto a parte visual quanto a **usabilidade e acessibilidade**.
